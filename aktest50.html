تضمين صفحة المسلسلات مع الانتقال إلى عنصر محدد بواسطة ID

واجهة التضمين جاهزة
ⓘ
حماية النوافذ المنبثقة مفعّلة: يعمل إطار Akwam بصلاحيات محدودة؛ يسمح بتشغيل JavaScript والنماذج، لكنه لا يمنح الصفحة صلاحية فتح نوافذ منبثقة أو التنقل إلى الصفحة الأم. اكتب أيضاً الـ ID الحقيقي الموجود داخل صفحة Akwam؛ الاسم series-list في المثال ليس ID مؤكداً. عند الضغط، يضيف الملف هذا الـ ID إلى نهاية رابط الصفحة كـ #ID، فيحاول المتصفح الانتقال إلى العنصر تلقائياً.

جارٍ تحميل صفحة Akwam داخل الإطار…

يتضمن الإطار خاصية sandbox من دون صلاحيات allow-popups أو allow-popups-to-escape-sandbox أو allow-top-navigation، ولذلك يمنع نوافذ popup ومحاولات نقل الصفحة الأم من داخل الإطار. هذا لا يحذف الإعلانات المدمجة داخل صفحة الموقع ولا يمنع كل أنواع التحويلات داخل الإطار. قد تتوقف بعض وظائف الموقع التي تعتمد على النوافذ المنبثقة أو التنزيلات أو تسجيل الدخول الخارجي. إذا لم تظهر الصفحة داخل الإطار، فقد يكون الموقع قد منع التضمين بسياسة أمنية مثل X-Frame-Options أو Content-Security-Policy؛ لا يمكن لملف HTML خارجي تجاوز هذا المنع. كما أن التمرير إلى ID داخل موقع خارجي قد لا يعمل من الصفحة الأم بسبب سياسة same-origin؛ إضافة #ID تطلب من المتصفح الانتقال إلى معرّف الرابط إن كان الموقع يدعمه.
